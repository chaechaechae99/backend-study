# 백엔드 단어장

백엔드 필수 개념을 공부하는 한 페이지짜리 사이트입니다. `index.html`을 브라우저로 열면 바로 동작합니다(설치 필요 없음).

## 기능

| 탭 | 내용 |
|---|---|
| 개념 사전 | 핵심 개념 52개를 5개 분류(HTTP·네트워크, API, 데이터베이스, 인증·보안, 서버·인프라)로 정리. 검색과 분류 필터 지원 |
| 암기 카드 | 카드를 뒤집어 뜻 확인. "외웠어요"는 진도에 반영, "모르겠어요"는 오답노트로 이동. 스페이스·← → 키 지원 |
| 퀴즈 | 4지선다 5/10/20문제. "설명 → 용어"와 "용어 → 설명"을 섞어 출제하고 해설 표시 |
| 오답노트 | 틀린 횟수 순으로 정렬. "오답만 퀴즈"에서 맞히면 횟수가 줄고 0이 되면 빠짐 |

## 저장

진도와 오답노트는 브라우저 `localStorage`(`backend-study-progress` 키)에 저장됩니다. claude.ai 아티팩트로 열면 로그인한 계정에 저장됩니다.

## 예시와 실습 연결

일부 예시는 XIAO ESP32-S3 실습 내용을 활용합니다(MQTT → Pub/Sub, Supabase → RLS·공개 키·PATCH, `.gitignore` → 환경 변수 등).
